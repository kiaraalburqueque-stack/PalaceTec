# PalaceTec

Casino con juego responsable. Proyecto integrador de Construcción y Pruebas de Software. Créditos virtuales, sin dinero real.

## Estructura

- usuario/backend: API del jugador
- usuario/frontend-web: React (jugador)
- usuario/frontend-movil: Kotlin (más adelante)
- administracion/backend: más adelante
- administracion/frontend-web: React (más adelante)
- database: scripts SQL y base de datos PostgreSQL compartida
- docs: documentos del proyecto
